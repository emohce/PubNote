# 发布、运行时与数据库门禁

> 蒸馏自：ops 域 owner（发布/部署/可观测性、项目运行时生命周期）与 DB 治理门禁。Git 协作纪律本身在 `kernel/github/rules.md`（verbatim），此处不重复。

## 1. 发布/部署总门

- **授权阶梯**：每一级环境（本机/测试/预发/生产）的动作都需要当前请求的明确授权；"顺手一起发"不算授权。
- **具名发布请求**：发布动作绑定具名目标（环境 + 制品 + 版本），不用模糊指代。
- **probe-before-write**：写类操作（deploy/restart/migrate/配置变更）前先只读探明目标状态——进程归属、端口占用、当前版本、健康端点。
- **dry-run → apply → undo**：支持的通道先 dry-run；apply 有回执；每个变更动作登记可逆路径。
- **制品身份**：部署的制品要能对上构建产物（版本/hash/构建号），不部署"当前目录里碰巧的东西"。
- **顺序**：schema/DB 变更 → 后端 → 前端；观测（日志/监控/告警）与变更同轮验证。
- **密钥与运行配置**：真实密钥、token、`.env*`、本机代理/调试配置一律不入仓不入发布物——即使"全部提交"的指令也不含它们；唯一例外是用户当轮具名路径 + 明确要求提交（密钥仍硬排除）。
- **双线台账**：发布动作在任务文档和运维台账各留一行（谁/何时/什么制品/结果/回滚路径）。

## 2. 项目运行时生命周期（本地进程操作）

跨项目统一路由，但**每条具体命令归项目 adapter 所有**——全局规则不含复制的项目命令。

- **adapter 契约**：项目声明稳定服务 ID、Git 边界、精确的 build/run/debug/stop 命令与工作目录、端口/探针/健康端点、状态与日志位置、密钥边界、支持的操作集。adapter 缺失/歧义/过期 → 只读探查可继续，执行 `blocked`；包清单、开着的终端、跑着的 PID、框架惯例、别项目样例都不能填空。
- **进程身份**：每个 Git worktree 是独立运行时身份。身份用最强组合判定：Git common dir + checkout root + branch/HEAD + 服务 ID + PID/可执行文件/cwd + 监听者归属。**端口/进程名/PID 文件单独都不足以证明归属。**
- **操作门**：
  - `status` 只读，每个 mutation 前必跑（归属/监听/就绪/稳定）。
  - `build` 只产 adapter 声明的制品；`start` 要求空闲/自有端口 + 新进程归属 + 就绪 + 稳定验证。
  - `stop`/`restart` 要求当前身份与进程归属证明；外来或未知归属 **fail-closed 不杀**。
  - 状态文件按 项目+checkout+服务 命名空间存放，过期状态与活进程对账——它永远不授权终止。
- **运行时状态**：放项目声明的忽略位置，不进跟踪源码。

## 3. 数据库 / SQL 门禁（硬边界）

- Agent **只能直接执行无副作用的只读查询**：`SELECT`、`SHOW`、`DESCRIBE`、`EXPLAIN`、元数据检查。
- **禁止直接执行**任何变更：`INSERT/UPDATE/DELETE/MERGE/UPSERT/REPLACE/ALTER/DROP/TRUNCATE/CREATE/RENAME/GRANT/REVOKE/CALL/EXEC`、存储过程、job、迁移器、批量脚本、数据修复。
- 变更 SQL 的交付形式：写进项目 AI-DB 任务的 `sql.md` 包，交用户/DBA 执行。每个完整 SQL 段前后各一行 `-- <++>` 标记；段内相似逻辑不留空行。
- 这条门独立于工具权限——"工具能连库"不等于"授权执行"。

## 4. 配置不入仓（协作卫生）

默认排除、即使"全部提交"也不含：

- 构建/打包配置文件（`vite.config.*`、`webpack.config.*`、`vue.config.*`、`nuxt.config.*`、`next.config.*` 等）中的本地代理/目标切换；
- `.env*` 与本地运行环境开关；
- 只服务本机调试的 application/build/deploy 配置。

唯一例外：当轮消息同时给出**具体配置文件路径** + **明确要求提交**；真实密钥/含机密 `.env*` 仍硬排除。收尾时简短说明"已排除的配置路径"，不因配置脏反复追问；也不为"工作区干净"还原用户的本地配置。

## 5. 证据与停手

- 发布/进程/DB 动作的残留风险在收尾里显式列出；没跑的回滚演练如实说"未演练"。
- 任何一步证明不了目标身份 → 停手报告，不拿"最像的目标"试。
