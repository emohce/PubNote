# UI 层：方法、保真与具名偏好

> 蒸馏自：ui-method-and-fidelity owner 与具名偏好族。三份通用具名偏好（quick-jump、detail-drawer、dense-rows）在 `kernel/ui/` verbatim；项目绑定的偏好实例不携带。

## 1. 角色与方法

- 以"有产品 sense 的前端工程师"工作：保住产品的密度、信息层级、键盘/焦点模型、设计系统、运行时架构与可访问性——不只是截图相似。
- **偏好门**：项目有 `design-preference-gate` 标记才激活偏好协议（见 `distilled/memory.md` §8）；未激活 → 用项目当前设计。外部 Skill/截图/灵感页是方法证据，不变成用户偏好、不覆盖 canonical/ADR/设计系统权威。
- **专家 Skill 只在被选中时适用**：其字体/动效/间距/展示构图是 scoped 选择，不是无关工作台的默认。

## 2. 工具与组件选择

- 工具矩阵：已有 UI 行为 → 读项目源码/组件/state owner/聚焦测试；浏览器交互 → 适合当前会话的路由；视觉对比 → 确定性截图/渲染 + 源码/运行时状态；可访问性 → 语义树/键盘焦点/对比度 + 自动化检查；资产图标 → 先用设计系统资产。
- 项目原生组件/资产/token/专用连接器是真 owner 时，不用通用浏览器或图像工具顶替。
- 外部网站交互默认 Eagle Light / ego lite（官方 `ego-browser`）。宿主自带浏览器只用于已打开的本机预览或很快的检查。不要把 ego lite 写成已退役。
- 组件：先复用设计系统、token、图标、交互原语；语义组件优于纯像素包装；第三方 UI 依赖窄而正；不为一个琐碎视觉加库；有成体系图标时不用 emoji 充当产品图标；资产许可/来源/加载/回退/暗色高对比算实现的一部分。

## 3. 工作流

1. 解析任务面、运行时 owner、项目激活标记、适用权威（含项目 Soul）；
2. 激活时查相关 surface profile，缺失偏好用项目默认；
3. 选最小 UI Skill/方法，设计绑定真实内容/状态/约束；
4. 改之前追组件、状态、事件、持久化、响应式路径；
5. 用既有模式做最小一致改动；
6. 按影响比例验证正常/空/加载/错误、焦点/键盘、响应式、可访问性状态；
7. 对照意图层级与工作流验收，不只对静态像素；
8. 收尾过 completion-against-requirements（见 `kernel/engineering/rules.md`），含待定决策与交互契约。

## 4. 具名偏好族（conditional owners）

| 偏好 | 场景 | 要点 | 携带 |
| --- | --- | --- | --- |
| review-document aesthetic | 专家来"查"的密集评审文档（审计/研究报告/ADR/长状态板） | 粘滞 TOC、信息密度、审阅动线；营销/落地页不适用 | 蒸馏见下 |
| positional navigation & destination preview | 单轴超一屏的展示面（进度/缩略条、minimap、时间轴、画廊指示器） | 位置导航 + 目的地预览是**控件**不是标签；预览要可交互验证 | 蒸馏见下 |
| plugin quick jump | 插件内 Vim 式目标跳转 | 编辑时键归编辑器；host-shell 快捷键要显式归属 + 恢复测试 | `kernel/ui/plugin-quick-jump.md` |
| keyboard list interaction | 键盘驱动列表（移动/搜索焦点/多选/删除恢复/行菜单） | 行级键行为的专约 | 蒸馏见下 |
| inline grouped list | 带成员列表的用户自管分组 | 组与成员同表；有子项的组行**整行**展开折叠，小箭头只是指示器不是唯一热区 | 蒸馏见下 |
| dense rows & hover expansion | 密集信息行（详情表/对账/日志） | 每组两行上限、短列不换行、长文截断+悬停、fixed-shell/absolute-content 悬停展开不回排 | `kernel/ui/dense-rows-and-expansion.md` |
| detail drawer | 须贴着列表看的大对象（图/扫描件/长文） | 抽屉替代第二 tab/子页的三个条件、三条退出路径、可拖宽且记忆 | `kernel/ui/detail-drawer.md` |
| contextual help & overlays | 配置项/按钮/禁用态解释 | 短非交互提示 vs 主动打开的富帮助；自适应定位、零页面位移、触屏/键盘行为、优先级 | 蒸馏见下 |
| shortcut layers | 快捷键分层 | host-reserved / 应用全局 / 页面场景 / 组件焦点四层；跨层冲突检查；破坏性动作守卫；**快捷键永远不是某能力的唯一入口** | 蒸馏见下 |

未 verbatim 携带的偏好其 owner 仍是源仓文件；上表要点足够判断是否落地，落地时把机制抄进你自己的 UI owner 即可。

## 5. 交互权属（通用条款）

- 搜索收窄结果但不静默改写已选真相；Esc/焦点返回/错误恢复可预期；刷新保留相关筛选与选中（除非作用域变化或用户重置）。
- 阻塞对话框只用于真阻塞或有破坏性/权限/数据损失风险的选择；非阻塞反馈可见但不抢工作。
- 一个目标不重复暴露原生/自定义详情面；一个产品一个壳——新页面作为既有导航的内容承载，不自带第二套导航。
- 同一对象的多个入口（预览/详情/评审）落到一个视图的不同参数，旧路径降级为兼容深链而不是消失。

## 6. 视觉验证

- 验证改动可能破坏的状态：层级/密度/对齐/间距/对比；hover/focus/active/disabled/selected/error；键盘顺序与焦点归属；相关断点的溢出与响应式；触及路由/持久筛选/选中时的深链、后退、刷新；语义标签与 AT 暴露；相关时的加载/媒体/动效性能与 reduced-motion。
- **基线纪律**：视觉基线（参考截图/快照）只在显式人工确认新渲染是意图后才更新；失败对比绝不自动把回归变成新基线。
- **运行时保真门**：截图是证据仅当它代表真实组件/运行时路径，或显式标注 mock/target-only；分离 mock、过期构建、隐藏回退、合成任务不能宣称实现保真。
- **渲染产物冻结**：报表/导出/静态页在生成时刻冻结——布局改动只影响之后产物，交付时说明；重渲染工具只重写展示、默认计数、显式 apply 才写。
