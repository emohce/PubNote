# Task Overview Sidecar Gate

<!-- rule-contracts: sidecar -->

This file is the sole normative owner of the Task Overview Sidecar gate. `process/rules.md` keeps the gate heading and a link-only stub for anchor compatibility; hubs, routers, templates and project adapters route here and must not restate the algorithm.

Sidecar is a decision gate, not a mandatory Agent. Root performs it main-only unless an independent read-only review materially improves discovery or acceptance.

- Start Explorer checkpoint: use before implementation only for unresolved cross-owner scope, broad repository discovery, conflicting current authorities or materially parallel read-only questions.
- Closeout Reviewer checkpoint: use after implementation only when an independent diff/evidence review materially lowers acceptance risk.
- A Sidecar never owns scope, writes, high-risk gates, canonical acceptance or final communication. Record `not applicable` with reason when Root evidence is sufficient.
