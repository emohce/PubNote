## Module Boundary

This folder holds assessment, review, audit and re-verification records for this task only. It is evidence, not an owner.

- Requirement authority: the task's own `spec.md` (link it relatively from the copied index)
- Verification authority: the task's own `verify.md`
- Handoff / state: the task's own `handoff.md`

An assessment never rewrites the assessed task's own documents. When an assessment conflicts with `verify.md`, the assessment's first-hand re-run evidence decides, and the result is written back into `verify.md`.
