# 详情抽屉（Detail Drawer）

本文件是跨项目**大对象详情**（大图、原件、长文档、并排比对）承载方式的 owner。
浮卡与说明层归 [contextual-help](contextual-help.md#L1)，密集行归 [dense-rows-and-expansion](dense-rows-and-expansion.md#L1)；
本文件只管「大东西开在哪、怎么关、能不能放大」。

## 1. 何时用抽屉

- 内容需要大面积才看得清（图像、扫描件、并排比对、长表），但读者**仍要保留当前列表 / 表格的位置**时，用侧向抽屉。
- 不要为「看大图」再开一个子页签或第二套页面：读者被迫离开正在核对的表，回来还要重新定位。
- 需要读者停下来做一次性抉择（确认、授权、破坏性动作）时用对话框，不是抽屉。

## 2. 打开与退出

- 抽屉从内容侧推出（左右布局的产品默认右侧），正文表格保持常显，不整页替换。
- 至少三条退出路径都要通：遮罩点击、显式`关闭`按钮、`Esc`。任何一条缺失都算缺陷。
- 抽屉打开期间锁住正文滚动，关闭后恢复；焦点回到触发它的那个入口。
- 抽屉是层级阶梯里的一层，不在抽屉里再叠第二层浮层承载明细——明细在抽屉内联展开。

## 3. 可调宽与记忆

- 抽屉靠内容侧的边缘常驻**拖拽把手**：按住横向拖即改宽，内容（尤其图像）随宽度放大。
- 给出上下限（下限保证内容可读，上限给正文留出可辨识的一条边），越界夹取而不是让抽屉盖满屏。
- 把手要可聚焦：方向键按固定步长微调；双击在默认宽与近满屏之间来回。
- 宽度按浏览器记忆，下次打开沿用；读写包在 try/catch 里，取不到就回默认宽。
- 把手随抽屉显隐，关闭后不得留在页面上。

## 4. 验证

记录可复现观测值：抽屉宽度从默认到拖拽后的实测值、内容（图像）宽度是否同步放大、
关闭后再次打开是否沿用记忆宽度、三条退出路径是否都生效。
